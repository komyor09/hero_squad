# Подключение базы данных Firebase к Hero Squad

Пока Firebase не подключён, сайт и админка работают в **демо-режиме**. В этом режиме данные хранятся только в одном браузере, поэтому сайт и админка видят друг друга, если открыты на одном компьютере. Чтобы телефоны однокурсников получали старт квеста и попадали в таблицу лидеров, подключите бесплатную базу Firebase. Это займёт около 10 минут.

## 1. Создайте проект
1. Откройте https://console.firebase.google.com и нажмите **«Создать проект»**.
2. Введите название, например `hero-squad`. Google Analytics можно выключить.

## 2. Создайте базу Realtime Database
1. В левом меню откройте **Build → Realtime Database** и нажмите **Create Database**.
2. Выберите регион (подойдёт `europe-west1`) и режим **Start in locked mode**.

## 3. Включите вход
1. Откройте **Build → Authentication → Get started → Sign-in method**.
2. Включите **Anonymous**. Через этот способ входят игроки, им ничего вводить не нужно.
3. Включите **Email/Password**. Через этот способ входит администратор.
4. На вкладке **Users** нажмите **Add user** и задайте e-mail и пароль администратора.

## 4. Разрешите ваш сайт
Откройте **Authentication → Settings → Authorized domains → Add domain** и добавьте `komyor09.github.io`.

## 5. Скопируйте настройки в сайт
1. Откройте **Project settings** (шестерёнка) → **Your apps**, нажмите на значок `</>` (Web) и зарегистрируйте приложение.
2. Скопируйте объект `firebaseConfig`.
3. Откройте файл `assets/js/firebase-config.js`:
   - замените `window.FIREBASE_CONFIG = null;` на скопированный объект. В нём обязательно должна быть строка `databaseURL`;
   - в `window.HS_ADMIN_EMAILS` впишите e-mail администратора из шага 3.

## 6. Защитите базу правилами
1. Откройте файл `database.rules.json` и замените **во всех местах** `admin@example.com` на e-mail администратора.
2. В Firebase откройте **Realtime Database → Rules**, вставьте туда содержимое файла и нажмите **Publish**.

Правила работают так:
- данные квеста, объявления и героев читают все, а меняет только администратор;
- каждый игрок может менять только свою строку в таблице лидеров;
- заявку может отправить любой посетитель, а читать заявки может только администратор.

## 7. Залейте изменения на GitHub
```
git add .
git commit -m "feat: firebase"
git push
```
После этого откройте `https://komyor09.github.io/hero_squad/admin.html`. Вверху должно быть написано **«● Firebase — онлайн»**.

### Как провести квест на паре
1. Откройте `admin.html` на ноутбуке и войдите.
2. Нажмите **«Режим проектора»**. На экране появятся QR-код и таблица лидеров.
3. Однокурсники сканируют QR-код. По желанию можно нажать **«Режим ожидания»** — тогда миссии будут заблокированы до старта.
4. Выберите длительность и нажмите **«Начать новый раунд»**. У всех появится окно ввода имени и отсчёт 3-2-1.
5. Отправляйте **объявления** («Осталась 1 минута!»). Они всплывают у всех на экранах.
6. Когда время выйдет или вы нажмёте **«Завершить раунд»**, у всех появятся итоги и место в рейтинге.

Попасть в админку также можно командой `admin` в терминале J.A.R.V.I.S. (клавиша «ё»).
